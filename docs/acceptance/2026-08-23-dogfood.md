# AnimFlow authoring platform dogfood acceptance

Date: 2026-08-23

Scope: CLI → Studio → local Presenter → immutable Publish → public Presenter → React SDK

Result: engineering acceptance passed

## Dogfood lecture

The shared fixture is [`examples/dogfood/ai-agent-runtime.animflow`](../../examples/dogfood/ai-agent-runtime.animflow), a Korean technical lecture on reliable AI agent runtimes.

- Source version: AnimFlow 2.1
- Story: `agentLecture`
- Scenes: 10
- Actions: 41
- Compiled duration: 600,000 ms
- Structure: seven nodes, eight directed edges, one policy callout
- Narration: one one-minute teaching cue per scene

The CLI validated and compiled the source without diagnostics. Runtime contract tests sample every scene start/midpoint/end in forward and reverse order and verify deep-equal frames; restart matches `sample(plan, 0)`.

## Product-path rehearsal

The Playwright dogfood opens the `.animflow` file through the Studio file input, confirms all ten cue cards, changes lesson metadata, opens the local Presenter, moves forward and backward, publishes through the UI, opens the immutable public URL, plays to the end, and returns Home to the first frame.

Two duration modes passed:

- deterministic clock: Chromium, Firefox, and WebKit fast-forward the exact 600,000 ms revision as part of the 36-test cross-browser suite;
- real time: Chromium replayed the public revision continuously at 1× for 600 seconds and completed the scenario in 10.3 minutes.

The dogfood found and fixed a real initialization race: Studio previously displayed “Ready to teach” before the authoring worker existed, so an immediately selected file was silently ignored. Readiness now follows the actual session and Open/Import stay disabled until it exists. File read rejection is also surfaced and the input is cleared only after reading finishes.

## Acceptance boundary

This record is engineering evidence, not fabricated user research. Two launch-validation items require external participants or credentials and are deliberately not claimed here:

- the median time-to-first-animation study with three Mermaid users;
- the external fixed-model 30-run Skill evaluation configured through `ANIMFLOW_EVAL_COMMAND`.

Likewise, the 10-minute artifact and continuous playback were rehearsed by automation; a human instructor's live delivery remains a product-content signoff, not an unresolved implementation defect.
