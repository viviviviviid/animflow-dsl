## 검증 범위

- 단위·통합 테스트 200개. 이번 변경의 회귀 테스트 26개 포함.
- `pnpm verify`: 버전 계약, 전체 테스트, 프로덕션 빌드, TypeScript 검사.
- Playwright: Chromium / Firefox / WebKit. 실제 편집, 원본 내보내기, 실행 취소, 프로젝트 저장/복구, 모바일, 모달, 드래그, 확대/이동, 발표, 로컬 게시/삭제 경로.
- 모든 기본 예제의 모든 장면을 다크/라이트 인터페이스에서 검사: 노드 겹침, 오버레이 겹침, 레이블 겹침, 텍스트 잘림, 캔버스 잘림.
- 별도 SDK 소비자 프로젝트: tarball 설치, 타입 검사, 브라우저 번들, SSR, 실제 worker 컴파일·렌더링.
- 독립 검토: 6개 노드 모양의 병렬 self-loop 및 좁은 출구. 경로당 1,001개 표본에서 이웃 노드 관통·중복 경로 0건.
- 기존 브라우저 성능 기준 8개 모두 통과. 100노드·150연결·30장면·600액션에서 cold-ready p95 88.8ms, warm compile p95 199ms, clone/freeze p95 48.6ms, worker heap 최대 8.69MB. 측정 환경과 원본 표본은 [성능 결과](2026-09-06-browser-performance.json)에 기록했다.

전체 브라우저 실행은 99개 중 98개 통과했고, Firefox 1회에서 초기 로딩 30초 제한을 넘겼다. Firefox 전체 재실행에서 해당 로딩 실패는 재현되지 않았고, 프로젝트 전환 직후 내보내기의 제목/소스 불일치를 추가로 발견해 수정했다. 수정 후 프로젝트·모달·드래그·모바일·포맷·Undo 관련 24개 검사를 Chromium / Firefox / WebKit에서 모두 통과했다. 초기 로딩 시간 초과의 원인은 확정하지 않았으며, 해당 테스트는 후속 두 실행에서 통과했다.

## 사용 방법

- **Canvas 아이콘**: 소스·인스펙터를 접어 그림에 집중. 다시 누르면 복원.
- **+/−**, **Fit**, **배경 드래그**: 현재 미리보기 확대·초기화·이동. 문서와 게시 결과에는 저장되지 않으며 장면 전환 시 초기화된다.
- **Format**: 유효한 소스를 정식 포맷으로 정리. Undo는 공백까지 원래 소스로 되돌린다.
- 모바일에서는 **Canvas / Source / Inspector**로 작업 영역을 전환한다.

## 범위와 한계

- 직선 경로를 명시하면 직접 연결한다. 장애물 우회는 orthogonal 및 막힌 curve에 적용한다.
- 사용자가 노드를 서로 겹치게 pin하면 빠져나갈 경로 자체가 없을 수 있다. 이 경우 핀 위치를 수정하거나 Auto-arrange를 사용한다. 임의의 모든 그래프에서 교차가 없음을 보장하는 전역 그래프 최적화는 아니다.
- 문자 폭은 DOM 없이 계산하는 결정적 추정값이다. 설치된 글꼴과 복합 이모지에 대한 모든 글리프의 픽셀 단위 동일성은 보장하지 않는다.
- 언어 문법을 무작정 확장하지 않고 기존 2.2 계약, 진단, 기하 계산, 편집·재생 일관성을 보강했다. 기존 2.0/2.1 호환과 `/legacy` 경로는 유지한다.
- 위 검증은 배포 전에 수행했다. 게시 E2E는 격리된 로컬 테스트 저장소를 사용한다.

자세한 언어 규칙은 [DSL Reference](../dsl-guide.md)에 반영했다.
