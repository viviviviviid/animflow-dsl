# Diagram fonts

Self-hosted fonts used only in diagram labels. Both are distributed under the SIL Open Font License 1.1; full copyright notices and licenses are included alongside the font files.

- Excalifont, copyright 2024 Excalidraw. Source: https://raw.githubusercontent.com/excalidraw/excalidraw/21ffaf4d76bf8554c3ba5561ab8ff41ce89b55fa/packages/excalidraw/fonts/Excalifont/index.ts
- Gaegu Regular, copyright 2018 The Gaegu Project Authors. Source: https://raw.githubusercontent.com/google/fonts/088df5c822dacc8fad9dd64dbbe5649cd6830e99/ofl/gaegu/

Excalifont subsets cover Latin, Greek, and Cyrillic; Gaegu supplies Korean handwriting. Other scripts use the platform fallback. Gaegu is losslessly compressed from the upstream TTF to WOFF2 with FontTools; glyphs, names, and metadata are preserved.
